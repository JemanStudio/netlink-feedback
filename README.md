# Netlink feedback

Bug reports and feature requests for [Netlink](https://jeman.net/netlink/), a Jeman app for Mac.

- **Found a bug?** [Open a bug report](../../issues/new?template=bug_report.yml)
- **Have an idea?** [Suggest a feature](../../issues/new?template=feature_request.yml)
- **Need help or have a question about a purchase?** See the [Netlink help page](https://jeman.net/netlink/support/) or email [support@jeman.net](mailto:support@jeman.net).
- **Security or privacy issue?** Please follow our [security policy](https://github.com/JemanStudio/.github/blob/main/SECURITY.md) instead of opening a public issue.

Please blur or remove your public IP address, location and any other private details from text and screenshots before posting.

This repository only tracks feedback. Netlink is not open source.
